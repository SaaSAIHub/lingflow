# LingFlow — Linguistic Asset Management Platform

**AI PDF and Image Translation in One Workspace**

[LingFlow](https://lingflow.ai/) is an online workspace for translating PDFs and text in images, aiming to preserve their layout and organizing source files and translated results in projects and a central file library. Use it to localize technical documents, product images and marketing content, then preview and download the translated assets.

**[Explore LingFlow](https://lingflow.ai/) · [Open the translation workspace](https://workspace.lingflow.ai/) · [View pricing](https://lingflow.ai/pricing)**

Registration is required. New users receive **1,000 trial credits**, valid for one calendar month from registration; check your account for the exact expiry. This is a limited free trial.

## AI PDF Translation, Image Translation and Asset Management

LingFlow brings translation tasks and multilingual content management into one workspace.

| Capability | What you can do |
| --- | --- |
| AI PDF translator | Translate PDF documents while aiming to retain page structure, tables and illustrations. |
| Scanned PDF translation | Use OCR to recognize and translate scanned text; quality depends on scan clarity. |
| PDF results | Preview and download translated-only and bilingual PDF results available in the task details. |
| AI image translator | Translate text in JPG/JPEG, PNG and WebP images and download the resulting images. |
| Translation projects | Add files, configure languages and track task progress together. |
| File library | Find, filter, rename, preview and download source files and translated assets. |

The website describes support for **100+ languages**. PDF and image translation have different language lists: check the options for your file type. Common needs include English–Spanish documents, English–Chinese manuals and Chinese–Japanese product images.

## How to Translate PDFs and Images with LingFlow

1. [Open the workspace](https://workspace.lingflow.ai/) and sign in with Google or register with an email address.
2. Create a translation project and upload files or select files from your library.
3. Choose the source and target languages available for each file type.
4. Review the estimated credit cost, name the project and start translation.
5. Track progress in the project and open completed results to preview them.
6. Check terminology, numbers and layout, then download the available PDF or image results.

Batch upload is listed among paid-user benefits on the pricing page. Up to **20 files per batch** can be added; tasks are scheduled in the background, so this does not mean all 20 translate simultaneously.

## Frequently Asked Questions

### Is LingFlow free?

LingFlow provides 1,000 trial credits for new registered users, valid for one calendar month. Further usage is available through paid passes or credit packs.

### Does LingFlow preserve PDF formatting?

LingFlow aims to preserve page structure and visual layout. Complex tables, unusual fonts and low-quality scans can affect results; check the translated document before use.

### Can LingFlow translate scanned PDFs?

Yes. LingFlow supports OCR and translation for scanned PDFs. Clear scans improve recognition; inspect numbers, labels and small text in the result.

### Can I download a bilingual PDF?

LingFlow supports translated-only and bilingual PDF results. Open the task details to see and download the available output files.

### Can I translate long PDFs or batches of files?

PDFs can be up to 50MB each. Check the page count and credit estimate before submitting a long document. Batch upload supports up to 20 files and is listed as a paid benefit; background scheduling determines processing order.

### Can I edit the translated image online?

A built-in image post-editor is not currently available. Preview and download the result, then use an external editing tool for changes to text or design.

### Are files processed only on my device?

No. Files are uploaded for processing and stored in your account's file library. You can manage and delete files there. See the [privacy policy](https://lingflow.ai/privacy-policy) for data handling details.

### What does linguistic asset management mean here?

It means keeping source files and translated results organized in translation projects and a central file library so they can be found, reviewed and reused.
