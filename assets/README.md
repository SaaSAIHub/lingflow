# LingFlow Image Sources

[Back to the product overview](../README.md)

These images accompany the official LingFlow product documentation. Existing product visuals are not presented as translations newly run for this repository.

| Files | Source and preparation |
| --- | --- |
| `lingflow-logo.png` | Current public website logo, from the website's `public/images/navbar-logo.png`. |
| `lingflow-homepage.jpg` | English homepage captured on October 18, 2026; cropped to the navigation and hero section, excluding browser UI and the floating contact control. |
| `technical-document-original.webp`, `technical-document-translated.webp` | Existing English–Chinese technical manual comparison from the [PDF translator product page](https://lingflow.ai/pdf-translator). Copied from the website's published image assets. |
| `headphone-poster-english.jpg`, `headphone-poster-spanish.jpg` | English–Spanish comparison in LingFlow's product materials, originally sourced from workspace translation demos. Captured from the complete enlarged images, excluding the surrounding document interface. |
| `travel-organizers-chinese-japanese.jpg` | Chinese–Japanese comparison in LingFlow's product materials, dated September 30, 2026. Captured from the complete displayed comparison, excluding surrounding browser space. |

The travel organizer's Chinese source image was created with an image generation tool; the Japanese result was supplied by the product owner after translation in LingFlow. The comparison preserves the supplied wording. Some usage and care wording changes meaning and needs review before publication.

The technical document is a product-page illustration, not a new benchmark. Safety instructions, units and parameter values require qualified review. The headphone poster's offer is part of the poster content and is not a LingFlow promotion.

All final images were visually reviewed for clarity, private information and outdated product allowances before publication. Cropping removes surrounding interface only; no translation text was rewritten or generated to replace the results. These comparison layouts do not assert a combined bilingual image export feature.

Public reference pages: [LingFlow](https://lingflow.ai/) · [PDF translator](https://lingflow.ai/pdf-translator) · [Workspace](https://workspace.lingflow.ai/).
