## PDF 翻译、图片翻译与语言资产管理

LingFlow 将翻译任务和多语言内容管理集中在一个工作台中。

| 功能 | 可完成的工作 |
| --- | --- |
| AI PDF 翻译 | 翻译 PDF，尽量保留页面结构、表格和插图。 |
| 扫描 PDF 翻译 | 通过 OCR 识别并翻译扫描文字，效果受扫描清晰度影响。 |
| PDF 输出 | 在任务详情预览、下载可用的单语译文和双语 PDF。 |
| AI 图片翻译 | 翻译 JPG/JPEG、PNG、WebP 图片中的文字，下载结果图片。 |
| 翻译项目 | 集中添加文件、设置语言和查看任务进度。 |
| 文件库 | 搜索、筛选、重命名、预览和下载源文件及翻译结果。 |

官网介绍覆盖 **100+ 语言**。PDF 和图片的翻译语言列表不同，请以相应文件类型的选项为准。常见需求包括英语与西班牙语文档、英译中手册、中译日商品图。

## 如何使用 LingFlow 翻译 PDF 和图片

1. [打开工作台](https://workspace.lingflow.ai/)，使用 Google 登录，或通过邮箱注册。
2. 创建翻译项目，从本地上传或文件库选择文件。
3. 为文件选择可用的源语言和目标语言。
4. 查看积分预估，填写项目名称并启动翻译。
5. 在项目中跟踪进度，打开已完成的结果进行预览。
6. 核对术语、数字和版式，下载可用的 PDF 或图片结果。

批量上传属于定价页列出的付费权益，单批最多 **20 个文件**。任务由后台调度，不代表 20 个文件同时完成翻译。

## 常见问题

### LingFlow 免费吗？

新注册用户有 1,000 试用积分，有效期一个自然月。后续可购买月卡或积分包。

### PDF 翻译能保留排版吗？

LingFlow 尽量保留页面结构和视觉布局。复杂表格、特殊字体或低清扫描件可能影响效果，使用前应检查译文。

### 可以翻译扫描 PDF 吗？

可以，支持 OCR 识别与翻译。清晰扫描有利于识别，请核对结果中的数字、标注及小字。

### 可以下载双语 PDF 吗？

支持单语译文和双语 PDF；请在任务详情查看并下载可用的结果文件。

### 能翻译长 PDF 或批量文件吗？

PDF 单文件上限为 50MB。长文档提交前应确认页数和积分预估；批量上传最多 20 个文件，属于付费权益，处理顺序由后台调度。

### 可以在线修改翻译后的图片吗？

目前尚未开放内置图片二次编辑器。可预览并下载结果，再使用外部工具修改文字或设计。

### 文件只在本地处理吗？

不是。文件会上传处理，并存储在账户文件库中，可自行管理和删除。数据处理详情见[隐私政策](https://lingflow.ai/zh/privacy-policy)。

### 这里的“语言资产管理”指什么？

通过翻译项目和集中式文件库组织源文件及译文，便于查找、复核和后续复用。
