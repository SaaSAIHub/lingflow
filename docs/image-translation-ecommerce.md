# Image Translation for Ecommerce with LingFlow

[Back to LingFlow overview](../README.md)

[LingFlow's AI image translator](https://lingflow.ai/image-translator) translates text in images while aiming to retain the visual layout. It is useful for product labels, specification charts, promotional posters and other ecommerce localization assets.

## Prepare product images

Use JPG/JPEG, PNG or WebP images with readable text. Follow the current workspace upload prompt for the image size limit. Keep the original image available for comparison and only upload content you have permission to process.

Choose the target language from the image translation options. PDF and image language lists differ; a language listed for PDFs should not be assumed to be available for images.

## Translate and download

1. Sign in to the [LingFlow workspace](https://workspace.lingflow.ai/).
2. Create a project and upload images or choose them from the library.
3. Select the source and target languages.
4. Review the estimated credits and start translation.
5. Preview each completed image, review its text and download the result.

The standard rate is 30 credits per image translation task. For example, three image translation tasks at that rate cost 90 credits. Review the actual estimate when configuring targets; do not assume one image can be translated into unlimited target languages for one charge.

Batch upload is listed as a paid benefit, with up to 20 files per batch. Background scheduling does not guarantee that every task finishes together.

## Review product information before publication

| Check | Why it matters |
| --- | --- |
| Product names and intended uses | A plausible translation may still describe the wrong product or use. |
| Dimensions and units | Keep values, multiplication signs, unit labels and measurement directions aligned. |
| Materials and package contents | Confirm the translation has not added or omitted an item. |
| Care and safety instructions | Verify the meaning against the original, with qualified review where needed. |
| Promotional copy | Check dates, discount conditions and language-specific phrasing. |
| Visual layout | Inspect clipping, overlapping text, small labels and the connection between labels and objects. |

The [Chinese–Japanese travel organizer comparison](../assets/travel-organizers-chinese-japanese.jpg) shows dimensions and specifications alongside product photos. Some wording about uses and care changes meaning, so a visual match should not be treated as proof that every phrase is correct.

The headphone poster comparison in the [overview](../README.md) shows English–Spanish marketing text. Its offer is part of the poster, not a LingFlow offer.

## Adjust text or design after translation

A built-in image post-editor is not currently available. Download the image and use an external editing tool if you need to adjust wording, type size, position or color. Review the final exported image again before publishing it to a storefront or social account.
