# Translating PDFs with LingFlow: OCR, Bilingual Output and Layout Review

[Back to LingFlow overview](../README.md)

[LingFlow's AI PDF translator](https://lingflow.ai/pdf-translator) translates digital and scanned PDFs, aiming to retain page structure, diagrams and tables. The workflow runs in the [online workspace](https://workspace.lingflow.ai/).

## Prepare a PDF for translation

Use a PDF up to 50MB that you have permission to upload. For scanned PDF translation, choose a clear, upright scan with legible text. OCR quality can vary with blur, compression, handwriting and page complexity. A scan's page image and the recognized text are different things: inspect the resulting wording, not only the visual layout.

For long manuals or reports, check the page count and estimated credits before submitting. Standard PDF translation costs 10 credits per page, using the page count verified during processing. File size alone does not tell you the credit cost. At the standard rate, 25 PDF pages correspond to 250 credits; use the actual estimate shown for your task.

## Create a PDF translation project

1. Sign in and create a project.
2. Upload PDFs or select them from your library.
3. Choose source and target languages from the PDF language options.
4. Review estimated credits, name the project and start translation.
5. Follow task progress and open completed results.
6. Preview and download the available translated-only or bilingual PDFs.

Batch upload is a paid benefit listed on the pricing page, with up to 20 files per batch. Background scheduling determines processing order; the batch limit is not a simultaneous-processing promise.

## Choose translated-only or bilingual PDF results

A translated-only PDF is useful for reading in the target language. A bilingual result helps readers compare languages. Check the actual output choices in task details. This guide does not prescribe a particular bilingual page arrangement for every document.

The side-by-side screenshots in the [overview](../README.md) illustrate selected content; an image comparison by itself does not establish an export feature.

## Review a technical manual, paper or report

| Content | Review before use |
| --- | --- |
| Technical manuals | Safety warnings, units, parameter values, component names and references to diagrams. |
| Research papers | Equations, variable names, citations, captions and reading order across columns. |
| Reports | Table headings, decimal separators, currencies, chart labels and footnotes. |
| Scanned documents | Missed lines, OCR substitutions, rotated text and small print. |

Compare the original and translated file at a readable zoom. Translation aims to preserve formatting, but long translated phrases, complex tables and unusual fonts can change the layout. Qualified review is particularly important for safety or other consequential instructions.

## If a result is incomplete or unavailable

Read the message in task details before retrying. Confirm that the file is within the size limit, the scan is legible, and sufficient valid credits are available. Do not repeatedly resubmit a task that is still processing. If the problem persists, contact support through the [Help Center](https://help.lingflow.ai/) or the [website's Contact Us control](https://lingflow.ai/), without publishing private files on GitHub.
