# Contributing to LingFlow Documentation

This repository contains the official product overview and guides for [LingFlow](https://lingflow.ai/).

Documentation pull requests are welcome: fix broken links, improve translations, clarify instructions, or correct product facts with a current official source and observation date. Keep the English, Simplified Chinese, Spanish and Brazilian Portuguese overviews consistent. Write commit messages in English.

For product support, use the [LingFlow Help Center](https://help.lingflow.ai/) or the Contact Us control on the [official website](https://lingflow.ai/). GitHub Issues are disabled. Do not include private documents, account details, credentials, signed URLs or customer information in pull requests.

Images must have a clear source and permission for reuse. Review each image for privacy and outdated information. Do not invent benchmarks, endorsements or translation results. Keep documentation changes focused; this repository does not contain the application source code.
